# Quy ước Echo Crater

- Dùng JavaScript module thuần và Node built-in test runner; không thêm dependency nếu chưa cần.
- Tệp văn bản UTF-8 không BOM; giao diện và tài liệu tiếng Việt.
- Không đưa token, thông tin cá nhân hoặc thông tin đăng nhập vào repository.
- Chạy `npm test` sau thay đổi logic; chạy `npm start` và smoke test trình duyệt trước khi bàn giao.
- Không deploy hay push GitHub; người dùng sẽ tự đưa mã nguồn lên repo.
